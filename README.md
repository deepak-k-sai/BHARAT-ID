# BHARAT-ID

BHARAT-ID is a biometric identity verification system designed for people with eroded or low-quality fingerprints.

## Features
- Citizen enrollment
- Fingerprint verification
- Biometric risk scoring
- Admin dashboard
- Audit logging
- Privacy token generation

## Tech Stack
- Python
- FastAPI
- Flask
- PostgreSQL
- HTML
- CSS
- JavaScript
